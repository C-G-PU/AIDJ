# 🤖 AI DJ Controller

Умное десктопное приложение для управления музыкой, в котором нейросеть выступает в роли диджея. Приложение анализирует вашу музыкальную базу, слушает ваши команды (через промпты) и самостоятельно подбирает треки, сводит их и управляет настроением сета.

## В текущей версии (MVP) реализовано:

1. **Анализатор аудио (Core / Analyzer)**
   - Использует библиотеку `librosa` для автоматического сканирования музыкальной папки.
   - Определяет BPM треков.
   - Поддерживает импорт дополнительных метаданных (настроение `Mood`, энергетика `Energy`) из сторонних файлов (CSV или JSON).

2. **База данных (Core / DB)**
   - Локальная база данных на SQLite (`library.db`).
   - Хранит пути к файлам и извлеченные метаданные для быстрого доступа.

3. **Аудио-движок (Core / Audio Engine)**
   - Построен на базе `pygame.mixer`.
   - Поддерживает две виртуальные деки (A и B) для воспроизведения звука.
   - Реализует плавное сведение (Crossfade) между треками.

4. **Мозг ИИ (Core / AI Brain)**
   - Интегрируется с локальными LLM через LM Studio / Ollama (API совместимое с OpenAI).
   - Принимает текстовый запрос от пользователя (например: "Включи что-нибудь энергичное"), анализирует базу данных треков и принимает решение.
   - Возвращает строгий JSON с планом: ID следующего трека, длительность перехода и сопроводительный текст.

5. **Графический интерфейс (UI / Main Window)**
   - Написан на `PySide6`.
   - Панель чата с ИИ, где отображаются действия диджея.
   - Таблица со списком всей музыки в базе (библиотека треков).
   - Кнопки для сканирования папок (работает в фоновом потоке, чтобы интерфейс не зависал) и загрузки метаданных.

## Как запустить приложение

**Требования:** Python 3.10+, установленная локальная языковая модель (через LM Studio, висящая на `http://localhost:1234/v1`).

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что вы находитесь в корне проекта и запустите:
```bash
export PYTHONPATH="$(pwd)"
python src/main.py
```

*Примечание: для работы на серверах без звуковой карты (например, в средах тестирования) используйте переменные окружения `SDL_AUDIODRIVER=dummy QT_QPA_PLATFORM=offscreen python src/main.py`.*
